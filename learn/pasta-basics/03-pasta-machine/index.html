パスタマシンの使い方

厚さ番号の意味・正しい通し方・形状ごとの目標厚さ

読了目安 5分 · 手打ちパスタ基礎シリーズ

厚さ設定の読み方

家庭用パスタマシン（インペリアなど）は通常1から7（または0から9）の番号で厚さを設定します。番号が大きいほど薄くなります。番号1は約3mm、番号7は約0.6mmが目安ですが、機種によって異なるため、最初に使うマシンで自分のメモを作っておくことを勧めます。

形状ごとの目標厚さ（7段階マシンの目安）

1番（3mm）: 最初の均し専用 2-3番: タリアテッレ、パッパルデッレ 4-5番: スパゲットニ、リングイネ（アタッチメント使用） 6番: ラザニア、カネッローニ 7番: ラヴィオーリ、タリオリーニ

正しい通し方

  1. 生地を手で平らに押しつぶし、番号1（最も厚い設定）で通す。生地を半分に折り、再度1番で通す。この折り返し作業を3〜4回繰り返す。生地表面がさらに均一になり、気泡が消える。
  2. 番号2に上げて1回通す。番号3、番号4と1段ずつ上げながら通していく。2段以上飛ばすと生地が引きちぎられる。
  3. 目標の番号まで到達したら1枚シートの完成。すぐカットするか、打ち粉をして乾燥させないように布巾をかぶせて待機させる。

生地が破れるときの原因と対処

破れの原因はほぼ3つに限られます。 1つ目はレスト不足。グルテンが弛緩していないため伸展性がない。2つ目は番号を飛ばした（1から3に跳んだなど）。3つ目は生地が乾燥してきた（作業時間が長い場合）。 解決策は、破れた生地を丸め直し、10分休ませてから再度1番から通し直すことです。乾燥が原因なら手を少し濡らして表面に湿気を与えます。
