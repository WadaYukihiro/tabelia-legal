食文化 · 共通

「おいしい」はどこで生まれるのか

実家の味噌汁、ニースのラタトゥイユ、村祭りの燻製の香り。料理と記憶のつながりから、その土地の文化を知って本場の料理を作る楽しさを考えます。

公開 2026.10.08 · 更新 2026.10.08 · 読了目安 6分

実家の味噌汁が、どんな名店の料理よりも恋しくなることがある。

特別な食材を使っているわけでも、洗練された調理法で作られているわけでもない。それでも、久しぶりに口にすると、ほっとするようなおいしさがある。

その理由を考えると、料理のおいしさは、味覚だけでは説明できないことに気づきます。

私たちは、味だけを食べているわけではない

映画『レミーのおいしいレストラン』に、印象的な場面があります。

辛口で知られる料理評論家アントン・イーゴが、ラタトゥイユを一口食べた瞬間、幼いころの記憶へと引き戻される場面です。

そこにあったのは、母親が作ってくれた料理と、温かな家庭の風景でした。

彼を驚かせたのは、単に料理の完成度が高かったからではないのでしょう。その味が、長いあいだ忘れていた感情まで呼び起こしたのです。

香りや味が過去の記憶を鮮やかによみがえらせる現象は、「プルースト現象」と呼ばれています。

私たちにも似た経験があるはずです。

冬にホットワインのスパイスが香ると、クリスマスマーケットの灯りや、冷たい空気の中で手にした温かなカップを思い浮かべる。あるいは、八角の甘く独特な香りに、アジアの市場や屋台の賑わいを感じる。

実際にその場所を訪れた記憶がなくても、香りをきっかけに、映画や本、旅先で知った風景を思い浮かべることがあります。

料理は、味覚だけで完結するものではありません。

その香りをどこで嗅いだのか。誰と食べたのか。どのような時間を過ごしたのか。

そうした経験や記憶が重なって、私たちの感じる「おいしい」は形づくられているのです。

一皿の料理には、その土地の記憶がある

では、自分にとって馴染みのない、遠い国の料理はどうでしょう。

初めて食べる料理には、知らない香りや、食べ慣れない味があるかもしれません。

けれど、その土地で暮らす人々にとっては、幼いころから何度も食卓に並び、家族や季節の記憶と結びついてきた味なのかもしれません。

南フランスのニースに伝わるラタトゥイユも、その一つです。

なすやズッキーニ、パプリカをそれぞれ炒め、トマトと合わせて煮込む。夏にたくさん作り、翌日にも温め直して食べる。

そこには、地元で採れる野菜を使い、日々の食卓を営んできた人々の暮らしがあります。

また、イタリアのアドリア海沿岸にあるセニガッリアの料理人、マウロ・ウリアッシは、あさりのスパゲッティに燻製の風味を加えた料理について、その香りが村祭りの網焼きの記憶を呼び起こすと語っています。

燻製の香りは、単に味に複雑さを与えるためだけのものではありません。

それは、土地の風景や、そこに暮らす人々が共有してきた時間を表現するものでもあるのです。

私たちが何気なく食べる一皿にも、そんな物語が隠れているのかもしれません。

自分の知らない「おいしい」に出会う

世界には、実にさまざまな味や香りがあります。

ある土地で愛されてきた料理が、別の土地で育った人にとっても、最初からおいしく感じられるとは限りません。

独特の発酵臭、強い酸味、馴染みのない香辛料。

初めて口にしたとき、少し戸惑うこともあるでしょう。

そんなとき、食べ慣れた調味料を足して、自分の好きな味に近づけることは簡単です。それも料理の楽しみ方の一つです。

ただ、その前に少しだけ、その味が生まれた理由を考えてみる。

なぜ、この料理にはこの香辛料が使われるのだろう。

なぜ、この地域では、この食材を発酵させるのだろう。

なぜ、何世代にもわたって、この作り方が受け継がれてきたのだろう。

その答えは、土地の気候や風土、食材の保存方法、宗教や祭り、あるいは家族の暮らしの中にあるかもしれません。

背景を知ることで、最初は不思議に感じた香りが、その土地の文化を伝えるものに変わっていく。

もちろん、由来を知ったからといって、すべての味が好きになるわけではありません。

それでも、自分の好みだけで判断するのではなく、その土地で愛されてきた味を、まずはそのまま楽しんでみる。

それは、料理を通じて、異なる文化に触れることでもあります。

私たちが慣れ親しんだ「おいしい」の外側には、まだ知らないおいしさが、きっとたくさんあるのです。

タベリアが、本場の味にこだわる理由

タベリアが本場の料理にこだわるのは、現地の味こそが誰にとっても一番おいしいと考えているからではありません。

その一皿に込められた、土地の歴史や文化、人々の暮らしまで味わってほしいからです。

料理は、単なる材料と調理手順の組み合わせではありません。

同じ食材を使っていても、切り方や火の入れ方、香辛料の使い方が違えば、そこに表れる土地の個性も変わります。

長い時間をかけて受け継がれてきた作り方には、その土地の人々が大切にしてきた味があります。

だからこそ、タベリアでは、できる限り現地の作り方を尊重し、料理の背景にある歴史や文化も一緒に伝えたいと考えています。

もちろん、家庭で作る以上、手に入らない食材もあれば、調理環境の違いもあります。すべてを厳密に再現する必要はありません。

大切なのは、形だけ本場らしくすることでも、正解の味を押しつけることでもないのです。

その料理が、なぜその土地で生まれ、どのように愛されてきたのか。

そんなことに思いを巡らせながら、いつもの食卓とは少し違う味を楽しんでみること。

それが、タベリアの考える、本場の料理を作る楽しさです。

いつもの食卓から、まだ知らない土地へ

遠い国の料理を食べるために、必ずしも飛行機に乗る必要はありません。

ニースのラタトゥイユを作る日には、南フランスの夏の食卓を思い浮かべてみる。

イタリアの郷土料理に挑戦する日には、その一皿が生まれた町の風景や、そこで暮らす人々のことを知ってみる。

料理の背景を知ってから口にする一口は、何も知らずに食べるときとは、少し違って感じられるかもしれません。

そして、初めて出会う味を好きになれなくても、そこに込められた文化を面白いと思うことはできます。

やがて、その香りが好きになったり、いつか現地を訪れたときに、知っている料理の名前を見つけて嬉しくなったりすることもあるでしょう。

料理は、お腹を満たすだけのものではありません。

一皿を通じて、まだ知らない土地の暮らしに触れ、そこで生きてきた人々の記憶や文化に思いを馳せることができる。

そして、そんな発見が加わることで、私たちの「おいしい」は、もっと豊かになっていくのだと思います。

次の週末は、まだ食べたことのない国や地域の料理を、一つ作ってみませんか。

いつもの台所から、少し遠い土地の食卓を訪ねるように。
